# 화면 연습 canonical 획순 표준

버전: `canonical-kids-v2-2026-07`

이 문서는 화면에 보이는 흐린 글자, 현재 획, 완료 획, 방향 안내와 자동 판정이 함께 사용하는 유일한 획 기준을 설명한다. 한 획은 펜을 댄 시점부터 떼는 시점까지의 연속 경로다. 꺾인 획은 여러 선분을 가진 하나의 polyline으로 저장한다.

## 공통 규칙

- 모든 좌표는 0~1 정규화 좌표다.
- 직선은 수평 또는 수직으로 정렬한다.
- 꺾인 획은 꼭짓점을 `waypoints`로 저장하고 판정 시 통과 여부를 검사한다.
- 원은 위 중앙에서 시작해 시계 방향으로 닫는다.
- 쌍자음은 왼쪽 자음을 먼저 쓴 뒤 오른쪽 자음을 쓴다.
- 복합 모음은 가로 모음 성분을 먼저, 세로 모음 성분을 다음에 쓴다.
- 겹받침은 왼쪽 받침을 먼저, 오른쪽 받침을 다음에 쓴다.
- 초성과 종성에서 같은 자모는 같은 기본 획순을 사용한다.

## 음절 배치

- 세로 모음·받침 없음: 초성 왼쪽, 중성 오른쪽.
- 세로 모음·받침 있음: 초성·중성은 상단, 종성은 중앙 정렬된 하단 영역.
- 가로 모음·받침 없음: 초성 상단, 중성 하단.
- 가로 모음·받침 있음: 초성 상단, 중성 중단, 종성 하단.
- 복합 모음: 가로 성분과 세로 성분을 서로 다른 배치 박스로 변환한다.
- 겹받침: 종성 박스 안에서 좌우로 축소 배치한다.

실제 좌표, 획수와 경유점 기대값은 `src/practice/strokeTemplates.ts`, `src/practice/syllableLayout.ts`, `src/practice/strokeStandard.ts`와 자동 테스트가 함께 고정한다.
